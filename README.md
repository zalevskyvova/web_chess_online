# ♟ Web Chess Online

Онлайн шахова гра з можливістю гри проти бота та мультиплеєра через кімнати.

---

## 🚀 Останні оновлення (Гілка `zalevskyvova_branch`)

У межах останніх оновлень інтерфейс гри було кардинально перероблено, додано сучасну преміальну естетику та покращено взаємодію з користувачем:

- 🎨 **Кастомні піксельні фігури**: Повністю замінено застарілі текстові Unicode-символи фігур на унікальний набір піксельних зображень у форматі PNG (імпортовано та оптизовано з папки `SHAHMATY`):
  - **Золотисто-світлі фігури** (`wP`, `wB`, `wR`, `wN`, `wQ`, `wK`) — для білих.
  - **Темно-сині фігури** (`bP`, `bB`, `bR`, `bN`, `bQ`, `bK`) — для чорних.
- 🔲 **Сучасна сіра дошка**: Перефарбовано клітинки у гармонійну сіру палітру, що знижує втому очей та надає грі сучасного вигляду (світлі клітинки — `#b8bcbe`, темні — `#4e5254`).
- 🖼️ **Металевий бортик**: Навколо шахової дошки додано стильний темно-металевий бортик (`#2d3135` товщиною 6px) з глибокими об'ємними тінями.
- ✨ **Динамічний контраст координат**: Позначення літер та цифр на краях дошки тепер адаптуються до кольору клітинки (`coord-on-light` / `coord-on-dark`), що гарантує чудову читаність за будь-якого фону.
- ⚡ **Мікро-анімації**: Фігури плавно збільшуються при наведенні курсору (`transform: scale(1.08)`) для створення приємного фізичного відгуку під час ходу.

## 📋 Опис проєкту

Web Chess Online — це веб-додаток для гри в шахи, побудований на базі **FastAPI**. Він підтримує два режими гри:

1. **Гра проти бота** — бот використовує [Lichess Cloud Eval API](https://lichess.org/api#tag/Analysis/operation/apiCloudEval) для розрахунку найкращого ходу з налаштовуваною складністю.
2. **Мультиплеєр** — гра з іншим гравцем у реальному часі через індивідуальні кімнати.

### Ключові можливості
- ⏱ **Контроль часу** — 9 варіантів на вибір: `1+0`, `3+0`, `1+1`, `3+2`, `5+0`, `10+0`, `15+10`, `30+0` та без обмежень.
- 🤖 **Рівні складності бота** — `easy` (легкий), `medium` (середній), `hard` (важкий), `unbeatable` (непереможний).
- 🏳 **Здача партії** та **пропозиція нічиєї** в один клік.
- 📜 **Історія ходів** у класичній SAN-нотації, що оновлюється в реальному часі.
- 🔄 **Автоматичне очищення** неактивних кімнат (після 5 хвилин бездіяльності).

## 🛠 Технології

| Компонент | Технологія |
|-----------|------------|
| **Backend** | [FastAPI](https://fastapi.tiangolo.com/) |

| **ASGI сервер** | [Uvicorn](https://www.uvicorn.org/) |
| **Frontend** | HTML5 (Semantic), CSS3 (Modern Flexbox/Grid), Vanilla JavaScript |

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію

Переконайтеся, що ви перебуваєте на правильній гілці:
```bash
git clone -b zalevskyvova_branch https://github.com/zalevskyvova/web_chess_online.git
cd web_chess_online
```

### 2. Створення віртуального середовища

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 4. Запуск сервера

```bash
uvicorn main:app --reload
```

Після запуску гра буде доступна у браузері за адресою: **[http://localhost:8000](http://localhost:8000)**

## 📡 API Ендпоінти

### `POST /create-room`
Створити нову ігрову кімнату.

**Тіло запиту:**
```json
{
  "time_control": "5+0",
  "difficulty": "medium",
  "against": "bot"
}
```

| Параметр | Тип | Опис |
|----------|-----|------|
| `time_control` | `string` | Варіанти часу: `1+0`, `3+0`, `1+1`, `3+2`, `5+0`, `10+0`, `15+10`, `30+0`, `unlim` |
| `difficulty` | `string` | Складність бота: `easy`, `medium`, `hard`, `unbeatable` |
| `against` | `string` | Опонент: `bot` або `player` |

**Відповідь:**
```json
{
  "room_id": "ABC123",
  "color": "white"
}
```

---

### `POST /join-room`
Приєднатися до існуючої ігрової кімнати.

**Тіло запиту:**
```json
{
  "room_id": "ABC123"
}
```

**Відповідь:**
```json
{
  "joined": true,
  "room_id": "ABC123"
}
```

---

### `POST /move`
Здійснити хід на шаховій дошці.

**Тіло запиту:**
```json
{
  "move": "e2e4",
  "color": true,
  "room_id": "ABC123"
}
```

**Відповідь:**
```json
{
  "success": "e7e5",
  "status": "playing",
  "turn": "White",
  "w_timer": 300,
  "b_timer": 300,
  "move_history": "1. e4 e5"
}
```

---

### `POST /board`
Отримати актуальний стан дошки.

**Тіло запиту:**
```json
{
  "room_id": "ABC123"
}
```

**Відповідь:**
```json
{
  "current_FEN": "rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1",
  "w_timer": 300,
  "b_timer": 300,
  "status": "playing",
  "turn": "White",
  "move_history": ""
}
```

---

### `POST /resign`
Здатися у поточному матчі.

**Тіло запиту:**
```json
{
  "room_id": "ABC123",
  "turn": true
}
```

**Відповідь:**
```json
{
  "status": "resigned",
  "winner": false
}
```

---

### `POST /draw`
Запропонувати, прийняти або відхилити нічию.

**Тіло запиту:**
```json
{
  "room_id": "ABC123",
  "turn": true,
  "accept": true
}
```

**Відповіді:**
- `{"status": "draw_offered"}` — нічию запропоновано
- `{"status": "draw"}` — нічию прийнято (гра завершена внічию)
- `{"status": "draw_declined"}` — нічию відхилено
